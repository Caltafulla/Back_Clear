# Back Clear - Frontend (scaffold)

This is a minimal scaffold for the Frontend application (React + TypeScript + Vite).

Quick start

1. Install dependencies

```powershell
cd frontend
npm install
npm run dev
```

2. Build and preview

```powershell
npm run build
npm run preview
```

Docker

Build and run with Docker Compose:

```powershell
docker compose -f docker-compose.frontend.yml up --build
```

Env

- VITE_API_URL defaults to http://localhost:3000/api
